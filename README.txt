Описание программы «GitHub User Finder»
Автор
Котов Дмитрий.

Краткое описание программы
«GitHub User Finder» — это простое и удобное графическое приложение для поиска пользователей на платформе GitHub. Программа позволяет быстро находить профили по логину, просматривать основную информацию (имя, блог, количество подписчиков и репозиториев) и сохранять понравившихся пользователей в избранное. Все избранные логины сохраняются в отдельный файл JSON для последующего использования.

Инструкция по запуску
1. Установка зависимостей
Для работы приложения требуется библиотека requests (для взаимодействия с GitHub API). Установите её с помощью pip:

Копировать
pip install requests
tkinter входит в стандартную библиотеку Python, поэтому его устанавливать отдельно не нужно.

2. Запуск программы
Сохраните предоставленный код в файл с именем github_user_finder.py.
Откройте терминал (командную строку) в папке с файлом.
Выполните команду:
bash
Копировать
python github_user_finder.py
(Если у вас установлено несколько версий Python, используйте python3 вместо python).
После запуска откроется графическое окно программы.

Примеры использования и работы программы
Поиск пользователя
Введите логин интересующего вас пользователя в поле ввода (например, gigachat или octocat).
Нажмите кнопку «Поиск».
В списке ниже появятся данные:
Логин: gigachat
Имя: GigaChat
Блог: —
Подписчики: 15000
Репозиториев: 42
Добавление в избранное
После успешного поиска пользователя выделите его данные в списке результатов.
Нажмите кнопку «⭐ Добавить в избранное».
Появится сообщение об успешном добавлении. Логин пользователя будет сохранён в файл favorites.json в той же папке, что и программа.
Обработка ошибок
Если поле поиска оставить пустым и нажать «Поиск», появится предупреждение: «Поле поиска не должно быть пустым».
Если ввести несуществующий логин, программа покажет сообщение: «Пользователь не найден».
Если попытаться добавить в избранное пользователя, не выбрав его из списка, появится предупреждение: «Пожалуйста, выберите пользователя из списка результатов».
